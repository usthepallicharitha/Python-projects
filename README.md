# Python Projects 🚀

A collection of Python mini-projects built for learning and practice, covering GUI apps, games, automation, APIs, and email authentication

## 📂 Projects Included

| # | Project | File | Description | Tech Used |
|---|---------|------|-------------|-----------|
| 1 | Alarm Clock | `alarm_clock.py` | Set an alarm that rings at a chosen time | Python, datetime |
| 2 | Chatbot | `chatbot.py` | Simple chatbot that replies to user messages | Python |
| 3 | Library Management System | `librarymgt_sys.py` | Manage books, members, and records | Python |
| 4 | Paint Application | `paint.py` | Draw on a canvas with different tools and colors | Tkinter |
| 5 | Snake Game | `snake_game.py` | Classic snake game with score tracking | Python |
| 6 | Typing Master | `typing_master.py` | Test and improve your typing speed | Python |
| 7 | Weather Forecast | `whether.py` | Get current weather for any city | requests, Weather API |
| 8 | WhatsApp Automation | `whatsapp.py` | Send WhatsApp messages automatically | PyWhatKit |
| 9 | QR Code Generator | `Qr_generator.py` | Generate a QR code from any link or text | qrcode, Pillow |
| 10 | User Authentication with Gmail | `user_authentication_with_gmail.py` | Verify users by sending email through Gmail | smtplib |

---

## 🛠️ Requirements

- Python 3.x
- Tkinter (comes with Python)
- Libraries listed below

Install everything with:

```bash
pip install requests pywhatkit qrcode[pil]
```
## ▶️ How to Run
1. Clone the repository:
```bash
git clone https://github.com/YOUR-USERNAME/Python-projects.git
cd Python-projects
```
2. Run any project by its file name (include the `.py`):
```bash
python Qr_generator.py
```
